
# Fed-ARS: 基于对抗响应分离的联邦学习鲁邦防御方法🛡️

> **项目定位**：（CCF-A在投）本项目专门用于模拟和分析联邦学习（Federated Learning）环境下的数据/模型中毒攻击及其相应的防御策略。

---

## 🛠 1. 环境配置

本项目建议在 **Mac M4 (Miniconda)** 环境下运行。

1. **克隆项目**：
   ```bash
   git clone [https://github.com/Diz-JIA/Fed-ARS.git](https://github.com/Diz-JIA/Fed-ARS.git)
   cd Fed-ARS
   ```

2. **安装依赖**：
   你可以运行项目中的 `requirement.txt` 脚本或手动安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

---

## 🚀 2. 如何运行

使用以下指令启动主程序，通过 `-s` 参数切换不同的实验场景（若不指定则运行全部场景，场景具体说明见 3）：

```bash
# 运行示例
python main.py -s 1
```

### 参数详解
* **`-s` (Scenario)**: 指定运行场景编号。支持单选或组合运行（本实验具体组合逻辑请参考源码）。
* **配置修改**: 所有的FL基础参数、攻击参数、防御参数等均可在 `config/` 目录下的配置文件中随心修改。

---

## 📑 3. 实验场景说明

项目目前内置了三种标准实验场景，方便进行消融实验对比：

| 场景编号 | 场景图标 | 场景名称 | 详细说明 |
| :--- | :---: | :--- | :--- |
| **1** | 🟢 | **无攻击 (Baseline)** | 纯净的联邦学习环境，用于测试全局模型的最优性能。 |
| **2** | 🔴 | **有攻击无防御** | 模拟攻击者注入毒化数据获上传恶意更新，观察模型准确率的下降。 |
| **3** | 🛡️ | **有攻击有防御** | 激活防御算法对抗攻击。 |

---

## ⚙️ 4. 核心功能
- [x] 支持对比多种联邦学习SOTA防御。
- [x] 集成主流中毒攻击手段。
- [x] 提供可视化防御效果对比。
- [x] 适配 Mac M4 芯片加速（可替换 cuda）。
